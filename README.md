# GeneWeaver

GPU-Accelerated CRISPR Alignment and Off-Target Analysis Engine.

## Objective

Develop a modular bioinformatics application for identifying
potential CRISPR off-target DNA sequences.

## Technology Stack

- Python
- BioPython
- NumPy
- Textual
- Rich
- Dask
